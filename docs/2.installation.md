---
title: Installation
description: Add the Database console to an AntelopeJS project that already runs the DMS and a database.

---

Add the module to a project that already runs the DMS. It needs no migration. It reads the schemas that other modules register, and it keeps the diagram layouts, diagram notes, query history and saved queries in its own `dms-database` schema.

::steps
### Add the module

Run the CLI from the project root:

```bash [Terminal]
ajs project modules add @antelopejs/dms-database
```

The command adds an `@antelopejs/dms-database` entry to the `modules` map of `antelope.config.ts` and downloads the package.

### Configure the module

The module works without configuration, so you can skip this step. To show the database name on the Overview and label your schemas, add a `config` block to the entry:

```ts [antelope.config.ts]
import { defineConfig } from "@antelopejs/interface-core/config";

export default defineConfig({
  name: "my-project",
  modules: {
    "@antelopejs/dms-database": {
      source: {
        type: "package",
        package: "@antelopejs/dms-database",
        version: ">=0.3.1 <1.0.0",
      },
      config: {
        driverLabel: "MongoDB",
        schemaLabels: {
          "app-*": { label: "Application", color: "info" },
        },
      },
    },
    // The DMS, database and API modules go here too.
  },
});
```

[Configuration](/docs/modules/database/configuration) lists every option.

### Restart the backend, then the frontend

Restart the backend first. The module registers its Vue frontend module, with the `DmsDatabase` component prefix, when the backend loads it. Then restart `ajs dms dev`, or rebuild the frontend with `ajs dms build`, so that the dashboard includes the new layer.

### Open the console

Sign in as the platform owner and open **Database** in the **Modules** catalog, or go to `/modules/database/overview`.
::

::tip
To see the module with sample data first, run its playground from a clone of the [`AntelopeJS/dms-database` repository](https://github.com/AntelopeJS/dms-database). Run `pnpm install` and `pnpm --dir playground install --ignore-workspace --frozen-lockfile`. Then run `pnpm dev`, and `pnpm frontend:dev` in a second terminal. The playground registers a `demo` schema and a `shop` schema with `eu` and `us` instances, and seeds both on first start.
::
