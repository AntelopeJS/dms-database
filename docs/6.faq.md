# FAQ

## The module does not appear in the Modules catalog

Only the platform owner sees it. Check that you are signed in as the owner, then that the backend logs `Module route /modules/database/... gated owner-only` at start. If they are missing, the module is not loaded: check its entry in `antelope.config.ts`, then restart the backend and the frontend, in that order.

## The Overview shows `—` as the database name

The Database interface cannot tell which driver it runs on. Set [`driverLabel`](/docs/modules/database/configuration).

## A table of my module is missing

The console lists the tables of registered schemas only. Check that your module calls `RegisterSchema(<schemaId>)` in its `start()` and declares the table with `@RegisterTable(<table>, <schemaId>)`.

## Why can't I edit rows?

The data browser is read-only when **All instances** is picked. Pick one instance to edit.

## Can I undo a saved edit?

For ten seconds after saving, **Undo** writes the previous values back. After that, edit the rows again, or restore from a backup: the module keeps no edit log.

## My write query asks me to type the table name

Every query that inserts, updates, replaces or deletes is measured by a dry run first, and runs only once you confirm by typing the table name. Read queries run straight away.

## The Table watch trigger fails to activate

On MongoDB, change streams need a replica set. Run MongoDB as a (single-node) replica set, or pick another trigger.

## Who can see my saved queries?

Only you, unless you tick **Share with team** when saving. Shared queries appear in every teammate's **Team** tab; only you can edit or delete them.
