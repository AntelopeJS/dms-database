## The module does not appear in the Modules catalog

Only the platform owner sees the module. Check that you are signed in as the owner. If you are, the backend has not loaded the module. Check its entry in `antelope.config.ts`, then restart the backend and the frontend, in that order.

## The Overview shows no database name

The Database interface cannot tell which driver it runs on, so the connection card shows only when the connection was last checked. Set [`driverLabel`](/docs/modules/database/configuration) to show a name.

## A table of my module is missing

The console lists the tables of registered schemas only. Check that your module calls `RegisterSchema(<schemaId>)` in its `start()` and declares the table with `@RegisterTable(<table>, <schemaId>)`.

## Why can't I edit rows?

The data browser is read-only when **All instances** is picked. Pick one instance to edit.

## Can I undo a saved edit?

For ten seconds after a save, **Undo** writes the previous values back. After that, edit the rows again or restore from a backup. The module keeps no edit log.

## My write query asks me to type the table name

The query console runs a dry run before every query that inserts, updates, replaces or deletes. The dry run finds what the query will touch, and a dialog asks you to confirm. You type the table name to confirm a delete, a change to more than one row, or a change whose row count the dry run cannot tell. A change to one row needs only a click. For single-row updates, **Don't ask again for single-row updates** skips the dialog until you close the browser tab. Read queries run straight away.

## The Table watch trigger fails to activate

On MongoDB, change streams need a replica set. The trigger then fails with `table-watch: cannot open change feed on <schema>.<table>`, followed by the driver's message. Run MongoDB as a replica set, or pick another trigger. A single-node replica set is enough.

## Who can see my saved queries?

Only you, unless you turn on **Share with team** when you save. Shared queries appear in the **Team** tab of every teammate, and only you can edit or delete them.
